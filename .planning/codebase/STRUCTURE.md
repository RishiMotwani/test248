## Directory Purposes

**`memory_optimizer/`** — the adaptive method itself. Pure policy components with no
API knowledge; everything callable by both the live server and the offline paper engine.

- Purpose: Factory of the proposed memory-optimization method
- Contains: `pipeline.py` (orchestrator), `scoring.py`, `decay.py`, `compression.py`,
  `budget.py`, `retrieval.py`, `extraction.py`, `embeddings.py`
- Key files:
  - `pipeline.py`: `AdaptiveMemoryPipeline` — the single ingest path, shared live/offline
  - `budget.py`: `token_budget_evict` + `fit_to_budget` — the only budget semantics
  - `decay.py`: `CategoryDecayEngine` — the paper's headline contribution
- No `__init__` exports (`memory_optimizer/__init__.py` is a one-line docstring);
  import modules directly: `from memory_optimizer.decay import CategoryDecayEngine`

**`baselines/`** — the four comparison arms, each a `BaseBaseline` subclass.

- Purpose: Uniform comparison policies consuming the shared fact stream (writer held fixed)
- Contains: `baseline_runner.py` (interface + `BaselineRunner`), `sliding_window.py`,
  `memgpt_style.py`, `summarization_only.py`, `vanilla_rag.py`
- Key files: `baseline_runner.py` — also has an LLM-free `__main__` self-test; exports
  `BaseBaseline`, `BaselineRunner`, `fact_matches`, `matched_gt_keys` via `__init__.py`

**`experiments/`** — the evidence machinery. One authoritative engine
(`paper.py`) + live metrics (`live.py`) + specialized scripts.

- Purpose: Reproducible paper experiments, gates, and reporting
- Contains:
  - `paper.py` (593 lines): offline seeded E1–E6 engine, `run_paper`/`run_seed`/`aggregate`/`write_manifest`
  - `live.py` (423 lines): live E1–E6 metric functions over server state
  - `e0_extraction_quality.py`: extraction vs 200-turn gold set
  - `e7_sensitivity_sweep.py`: one-at-a-time retriever/budget geometry sweep
  - `e8_external_benchmark.py`: LongMemEval-style needled-QA benchmark (`suite e8-v1`)
  - `run_multi_model.py`: writer-variance runs (llama3.1:8b / qwen2.5:7b / mistral:7b-instruct)
  - `qualitative_report.py`, `make_paper_artifacts.py`, `paper_state.py`, `statistics.py`
  - `e1_*…e6_*` 8-line deprecated stubs pointing at `run_experiments.py`
  - `results/` (gitignored): `manifest_{sha8}.json` + `latest_manifest.json`,
    `live_manifest.json`, `e0_extraction_quality.json`, `e7_sweep.json`, `e8_e8-v1.json`,
    `paper_state.json`, `qualitative_report.json`, `jobs_history.json`, `models/`
- Key files: `paper.py` (authoritative entrypoint per its docstring), `live.py` (used by `/api/experiments/run`)

**`data/`** — controlled test-input generation.

- Purpose: Deterministic synthetic conversations + E0 gold set
- Contains: `synthetic_generator.py` (`SyntheticConversationGenerator`, seeded),
  `build_gold_set.py` (seed 7 → `gold_labels/extraction_gold_200.json`)
- Key files: `gold_labels/extraction_gold_200.json` (committed, 200-turn E0 gold set)

**`ui/`** — the entire dashboard frontend in one file.

- Purpose: Live head-to-head demo UI + research job console
- Contains: `index.html` (1460 lines of inline CSS + vanilla JS, no build step)
- Key files: `index.html` — fetches `/api/*` endpoints directly; served by
  `server.py:1990` at `/dashboard`

**`artifacts/`** — regenerable paper outputs (gitignored).

- Purpose: LaTeX tables, figure-ready JSON, reproducibility payload
- Contains: `tables/table_e1_e2.tex`, `fig_data/e1_tokens_per_turn.json`,
  `fig_data/e4_distance_curves.json`, `reproducibility.json`
- Generated by: `experiments/make_paper_artifacts.py`

## Naming Conventions

**Files:**

- Library modules: lowercase snake_case — `pipeline.py`, `sliding_window.py`,
  `synthetic_generator.py`
- Experiment scripts: `e{N}_{descriptor}.py` — `e0_extraction_quality.py`,
  `e7_sensitivity_sweep.py`, `e8_external_benchmark.py` (legacy `e1_token_efficiency.py`…`e6_power_check.py` follow the same prefix)
- Results: `manifest_{8-char-sha}.json`, `latest_manifest.json`, `live_manifest.json`,
  `{pipeline}_{...}.json` (e.g., `e7_sweep.json`, `e8_e8-v1.json`)
- Dash/slash in model names → underscore: `model_slug()` in `experiments/run_multi_model.py:34` (`llama3.1:8b` → `llama3.1_8b`)

**Directories:**

- Method code: `memory_optimizer/`, `baselines/` (feature-plural kebab/snake)
- Data: `data/` with nested `gold_labels/`
- Outputs: `experiments/results/` (gitignored), `artifacts/` with `tables/` and `fig_data/` (gitignored)
- UI: `ui/` (single-file frontend)

**Python code:**

- Classes: `CamelCase` — `AdaptiveMemoryPipeline`, `CategoryDecayEngine`,
  `ImportanceScorer`, `MemoryRetriever`, `FactExtractor`, `SlidingWindowBaseline`
- Functions/methods: `snake_case` — `_build_comparison`, `step_decay_and_prune`,
  `dedupe_incremental`, `fit_to_budget`
- Module-private helpers prefixed `_` — `_token_overlap`, `_cosine`, `_keyword_category`,
  `_overlap` (a leading underscore marks "internal, import at your own risk")
- Config keys: snake_case — `max_context_tokens`, `decay_lambdas`, `similarity_threshold`

## Where to Add New Code

**New memory-policy component (e.g., a new decay variant):**

- Implementation: `memory_optimizer/<component>.py` (or a new module there)
- Wire it into the pipeline at `memory_optimizer/pipeline.py` ingest stage sequence
- Record the design decision in `brain.md` first (mandated by `brain.md:1-5`)

**New baseline method:**

- Implementation: `baselines/<name>.py` subclassing `BaseBaseline` (`baselines/baseline_runner.py:57`)
  — implement `observe()` / `held_facts()` / `retrieve()`
- Register in `BaselineRunner._make()` (`baselines/baseline_runner.py:181`) so `--methods`
  accepts it
- Optionally add a `RESEARCH_PIPELINES` entry in `server.py:1213` for dashboard launching

**New experiment script:**

- Implementation: `experiments/<name>.py` — reuse `load_settings`/`run_seed`/`replay_adaptive`
  from `experiments/paper.py`; write results into `experiments/results/`
- Add `--quick` wiring-gate behavior and register in `RESEARCH_PIPELINES` +
  `RESEARCH_GATES` (`server.py:1213,1309`) so the dashboard can run it

**New dashboard endpoint:**

- Route in `server.py` (grouped with the existing `/api/*` functions); fetch it from
  `ui/index.html` following the existing `fetch('/api/...')` pattern
- Keep request/response validation via Pydantic models where payloads are non-trivial

**New metric (e.g., an E9):**

- Metric logic in `experiments/paper.py:evaluate_method()` (offline) and
  `experiments/live.py` (live), keeping both arms' semantics aligned (the docstrings
  explicitly promise live/paper comparability)

**Utilities:**

- Shared helpers used by ≥2 modules belong in `memory_optimizer/` (e.g., token fitting in
  `budget.py`, matching in `retrieval.py`); do not copy `_cosine`/`_overlap` into new files
- Server-internal helpers stay in `server.py` unless another module needs them — prefer
  extracting to `memory_optimizer/` or `experiments/` as soon as the second caller appears

**Tests:**

- No test framework is installed. Verify via a `__main__` self-test or a `--quick` gate
  in the changed module; the "gates" research pipeline (`server.py:1302`) is the planned
  umbrella for these
